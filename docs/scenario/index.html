01 WORLD世界設定（近未来）

人の意識の仕組みが解明され、人格を持ったAIが動物の感覚に一時的に入れるようになった時代。平泉町はそれを防災に使う。

  • 人が見落とす低い場所（タイヤの裏、看板の足元、草の下）を、猫の目と鼻で見回り、赤いしるし＝消火栓の場所を記録する
  • 記録は町の側に残る。猫自身は覚えていない。翌朝、猫はただの猫に戻る
  • タキザワ、シラヤマは猫の名前ではなく、猫に入る人格の名前。「名づけ主」は、その人格に名前を与えた人
  • 猫が語らないのは「猫だから」ではなく、中にいるのが人の言葉を持たない記録用の人格だから。言葉の代わりに、方角・距離・秒数で残す

06 WHY CATS INCREASEなぜ猫が増えるのか

人格は町にいくらでも作れる。足りないのは体。

1町の人が野良猫を見つける「ねこの もくげきほうこく」から居場所を報告する。ゲームは何も要求しない。
2運営がなわばりを調べるその猫の縄張りを決め、cats.json の status を locked → unlocked にする。
3人格が体を得るシラヤマが目を覚まし、西の記録が白いまま、プレイヤーを待っている。猫えらびで「はいれる」になる。

07 STORY全体のストーリー

平泉の町は、昼は人のものです。住所があり、名前があり、消火栓は番地で呼ばれます。

けれど、人の目は高いところにあります。タイヤの裏、看板の足元、草の下。赤いものは、人が見ない高さに立っています。

だから町は、猫に頼むことにしました。

人の心の仕組みがわかった時代の話です。名前を持つ人格が、少しの間だけ猫の中に入れるようになりました。町はそれを「ぼうさいネコ」と呼びました。

タキザワは、東の猫に入る人格です。シラヤマは、西の猫に入るはずの人格ですが、まだ入る体が見つかっていません。眠っている、と町の人は言います。

夜、町は少しのあいだ、ねこの時間になります。人はいなくなり、名前は消え、消火栓は赤いしるしになります。呼び方は、方角と、距離と、においだけ。

あなたはタキザワを選び、東の猫の中に入ります。壁にぶつかります。タイヤの裏に赤が見えます。縄張りの端には、知らないにおいがします。赤いしるしを見つけるたび、記録に一つ、点が入ります。

ねこの時間が終わると、タキザワは猫から出ます。出る直前に、猫から借りた三つのもので今日を残します。

記録。この縄張りで、何を見て、何をまだ見ていないか。
鼻。まだ見ていない赤のうち、一番近いものの方角。
足。この体で、どれだけ速く回れたか。前より速かったか。

猫は眠ります。猫は何も覚えていません。記録だけが、町の側に残ります。

朝になると、人の町が戻ります。昨日と同じ町です。何も変わっていません。ただ、記録には昨日見た赤い点が残っていて、鼻はまだ見ていない方角を指したままです。

あなたはもう一度入ります。鼻の言う方角から回ります。体が道を覚えます。足が速くなります。

ある日、東の記録が埋まります。そのとき鼻は、西を向きます。西には、体を待っている人格がいます。

西の猫を起こすのは、あなたではありません。現実の町のどこかで、誰かが野良猫を見つけて、教えてくれたときです。そのとき、シラヤマは目を覚まし、西の記録が白いまま、あなたを待っています。

猫は見たものを残すだけです。それがどこにあったか、覚えるのは人の仕事です。
