ぼうさいネコ＠平泉 — ストーリー構造

feature-7：S04 リザルト画面のシナリオ（README 機能実装状況 No.21）。ゲーム結果がどのように文へ変わるかを、株本さんと開発メンバーで揃えるための1枚です。

1. 世界観（リザルト画面だけが持つ）

少し先の平泉。町の消火栓（赤いしるし）がどこにあるかを、人ではなく ねこの体を借りた人格 が歩いて記録する仕組みがある。それが「ぼうさいネコ」。

タキザワとシラヤマは猫の名前ではなく、その体に入る人格の名前。人格は町のどこかの猫に入り、 自分の なわばり（ひがしの なわばり／にしの なわばり）を走って、赤いしるしを 記録 に加える。

体（猫）がまだ見つかっていない人格は 眠っている。町の人が野良猫の居場所を通報すると、運営が cats.json を更新し、 その人格が体を得て選べるようになる。プレイヤーには「猫が増える」として見える。

この語（からだ・はいる・記録・眠っている）は public/data/messages.json の scenario ブロックにだけ現れます。 猫えらび・3D見回りの画面は無変更。世界観が合わなければ JSON の文言差し替えだけで戻せます。

3. ゲーム結果 → シナリオへ渡すフラグ（合流点）

ゲーム側が持つ結果を src/domain/scenario/context.ts の buildScenarioContext() が数値と真偽値に変換します。 シナリオ側（lines.ts）はこのフラグだけを見ます。

フラグ意味どこから来るか
totalなわばり内の赤いしるしの数（タキザワは4）hydrants.json × 縄張り半径
marks[]各しるしの「方角 距離」ラベルと、記録済みかスタート地点からの8方位・10m丸め

数字の絶対値（「4本」）は文に書かず、割合と差分で分岐します。猫や消火栓が増えても文が壊れません。

6. 1周の物語（数字を消して読む）

ねこの時間が終わる。人格は体から離れ、手元に残るのは 記録 だけ。

記録 は、白いところと赤いところがある地図。走った分だけ赤が増える。ひとつも見ていなければ、地図は白いまま。 全部見ていれば、この なわばり の記録は「できた」になる。

鼻 は、次に走る方向。いちばん近い「まだ」の方角と距離だけを告げる。全部見ていれば、 このなわばりに知らない匂いはない。眠っている人格がいれば、次の匂いは別のなわばりから来る。

足 は、体がどれだけ道を覚えたか。初めての体なら「はじめて はいった」。二度目以降は、前と比べて 速くなったか、同じか、まわりみちをしたか。

締めは、この町にまだ体を待っている人格がいるかどうか。いれば、町の人が猫を見つけたときに入れる。いなければ、次のねこの時間まで記録は残る。
